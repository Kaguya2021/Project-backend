# 🟢 Universal Ping / Uptime Monitor

Современная, минималистичная универсальная сервисная система мониторинга для бесплатных хостингов (Render, Vercel, Railway, Koyeb) и любых публичных HTTP/HTTPS API.

## 🚀 Возможности
- **Два режима работы:**
  - **Client Mode:** Запуск полностью в браузере (подходит для GitHub Pages без бэкенда).
  - **Server Mode:** Постоянный фоновый мониторинг с бэкенд API.
- **SSRF Защита:** Запрет обращений к `localhost`, приватным IP и внутренним ресурсам.
- **Поддержка Render Free:** Поддержание активности сервисов с пояснительными индикаторами.
- **Адаптивность:** Оптимизировано под мобильные устройства (Android/iOS).
